# BOIT 2.0 local preview

Open index.html directly or serve this directory with a local web server.

This redesigned static preview uses the original BOIT logo, locally saved fonts, and blue, purple, teal, white, and black palette. It includes an animated product orbit, gradient headlines, three product cards, anchor navigation, and an expandable platform inventory. Motion is disabled for reduced-motion preferences; the layout includes mobile styles.

Motor360, Medical360, and Life360 are working names with proposed scope. Cards are labeled as planned products. External navigation and discussion links lead to the original site. The local page is a visual prototype without a backend; the live website is unchanged.

Product illustrations were generated with the built-in image-generation tool. The complete prompts are saved in IMAGE-PROMPTS.md. Images are bundled locally in assets/.


## MIA homepage

Open home.html for the new homepage demo. Click Meet MIA in the hero or the floating launcher. The panel includes the supplied portrait and a clearly labeled, playable original Mila introduction.
